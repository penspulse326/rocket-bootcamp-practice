現職：火箭隊培訓學員

個人介紹與經歷

喜歡繪畫創作，透過學校計畫，赴日交換留學一學年，體驗異國人文衝擊，打磨美學素養。2020 年 3 月退伍後與家人一同創業開設早餐店，挑戰民生前線的勞動生活。

2021 年 9 月來到台北求職，期間雖已完成與台大遊戲社團隊之作品《Flip Tale 翻轉童話》並於 Steam 上架，但深覺個人美術實力不足，也無意投入遊戲美術設計的工作，目前僅維持個人創作。

現職為手遊營運專員，負責簡體內容本地化、市場調查、產品上市籌備等。因想轉換到發展性較好的領域，轉而開始學習前端程式設計。

程式學習歷程

大學必修 C/C++、Arduino 電子玩具設計，也選修過網頁設計、前後端整合、演算法等 ，有些許程式基礎。近一年在下班時間開始學習前端，以 Lidemy 的課程為基礎，配合 Huli 大的培訓課綱自學。去年也參加六角學院的 React 讀書會、F2E 精神時光屋活動，增加實作經驗。

自學遇過較大的卡關點是，Huli 大目前停辦培訓兩年，課綱的範例有些已失效，如 Twitch API，因此我必須從頭查閱新版的 API Document，但建置過程並非想像中困難，最後 成功寫出能抓取熱門主題並顯示當前流量最好的前幾名實況頻道的網站。

個人網站部署的作業則是無任何提示，要自行搜尋教學架設起來，在釐清 VM 設定、憑證問題、網域管理的問題後，成功在 GCP 上架設留言板。

加入火箭隊的動機

真正開始相信對前端有熱忱，是在 React 讀書會的期間，因為先前看 Lidemy 的教材時，對 React 的架構與寫法曾有難以理解的挫折，因此也很積極回答同學們在討論區的發問，只要是我實作過且能回答的，都會詳盡地描述，回復問題不只能夠釐清觀念，透過分享也能創造正向循環的學習能量。

參加 F2E 精神時光屋時，第一週我選了非常難做的稿件，還在摸索 svg 時就截止， 第二、三週雖然已經預習過，但常糾結在局部邏輯，而忘了要事先分析稿件與整體規劃，事後覺得切版能力、整體實作還有很大的進步空間，但沒有沮喪太久，活動結束後也陸續完成了後面兩週的主題。

因為「我學過」所產生的自負心態，過去常令我感到自卑，覺得沒有學以致用 ，才會沒有效率。但我明白這只是缺乏練習以及定期複習。讀書會的期間我體會到共學的重要性，對六角學院的印象也非常好。記得許多份攻略教材都是火箭隊的學長姊做的，因此我想不管過去曾經學過什麼，全心投入才是關鍵，並且還有很多新的挑戰等著我全力以赴。只有強度，才有進步。我期望的不是帶我一飛沖天的火箭，而是和有共同目標的夥伴們一起打造奔向未來的火箭。
